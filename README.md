# DARK PROMPT STUDIO v1.0

**Author:** DARK IBRAHIM (Md Ibrahim)  
**GitHub:** [https://github.com/darkibrahim](https://github.com/darkibrahim)

A lightweight, zero-dependency **Prompt-to-Code & GitHub ZIP Generator** designed for **Termux (Non-Root)** and Linux terminals.  
Enter a project prompt, and it automatically creates a complete GitHub-ready folder + `.zip` archive containing source code, `README.md`, `install.sh`, `run.sh`, and `.gitignore` — branded with **DARK IBRAHIM**.

---

## Features
- Custom **DARK IBRAHIM** ASCII Banner & Author Signature
- Generates both **Python CLI Tools** and **Dark-Themed Web Apps** (`index.html`, `style.css`, `app.js`)
- Auto-generates `README.md`, `install.sh`, `run.sh`, and `.gitignore`
- Automatically packages the output into a ready-to-upload `.zip` file
- Works 100% offline with Python 3 standard library (no root or pip packages needed)

---

## Installation & Usage (Termux / Linux)

```bash
bash install.sh
bash run.sh "create a dark theme network dashboard"
```

Or run in interactive mode:
```bash
python3 dark_prompt_studio.py
```
